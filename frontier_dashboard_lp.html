Core Features

不動産事業経営に
必要な機能をすべて

複雑な不動産開発プロジェクトの収益管理から、資金繰り、金融機関管理、フォーキャストまで。経営判断に必要な情報をリアルタイムで提供します。

◈
経営ダッシュボード
KPI5指標（売上高・粗利・営業利益・経常利益・純利益）をリアルタイムで表示。ステータス別・商品種別レポートをクリックでプロジェクトにドリルダウン。
KPIカード ドリルダウン 月次トレンド 商品種別
📊
フォーキャストレポート
月次P&Lを12ヶ月縦断で全項目表示。不動産売買6区分（1棟MS/AP・分譲・戸建・土地・中古）に分解。四半期色分け・上半期/通期集計付き。
月次P&L セグメント分析 物件別予測 利益率推移
🏠
物件詳細・収支推移
仕入契約締結→建築請負→販売中→買付→販売契約→販売決済→最終収支の7ステージで収支を可視化。各ステージの利益額・利益率をスナップショット表示。
7ステージ可視化 収支推移 資金繰り表 通知預金
📋
プロジェクト一覧
138件の全プロジェクトを一覧管理。ステータス・仕入契約月・仕入決済月・販売予定月・販売契約月・販売決済月・建築会社・金融機関・粗利率を横断表示。
全項目表示 フィルター 横断検索 期別絞込
🏦
金融機関管理
銀行別・長期/短期別借入残高推移、月次表、物件別金融機関リスト。返済期日順リスト（要注意90日以内・注意90〜180日・余裕あり）で資金リスクを早期把握。
借入残高推移 返済期日管理 物件別利息 通知預金
💴
資金繰り集計
全物件の資金繰り表データを集計・可視化。月次収支トレンドチャート（収入/支出バー＋月末残高ライン）。ステータス別・種別別フィルターで絞り込み分析。
月次収支 残高推移 物件別CF 集計レポート

Project Flow

仕入から決済まで
全フェーズを追跡

物件の誕生から完結まで、7つのステージで収支・リスクをリアルタイムに把握。経営者が知りたい情報を、知りたいタイミングで。

1
仕入契約締結
土地取得費・開発費を確定。想定売上高との収支シミュレーション開始。
土地取得費 登記費用 収支シミュレーション
2
建築請負締結
建築費・設計費を確定。原価構造が固まり、精度の高い収支予測が可能に。
建築費確定 設計費 着工スケジュール
3
販売中・買付
販売活動開始。買付証明書受領で売価確定。収支が現実的な数字に。
広告販売費 売価確定 ローン審査
4
販売契約・決済
売買契約締結で収益確定。引渡し・残金収受で事業完結。
売買契約 所有権移転 残金収受
5
最終収支（報酬金・金利含む）
金利・報奨金を含む最終収支を確定。事業精算レポートで次案件へ活かす。
最終金利 報奨金 事業精算
